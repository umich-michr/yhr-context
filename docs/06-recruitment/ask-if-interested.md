# Ask If Interested

An authorized study team member may use **Ask if interested** for a visible matching participant.

## Effect

The action:

- Does not directly contact the participant outside the application
- Does not create an expression of interest
- Promotes the study in the participant interface
- Displays a study-team-authored message
- Places the study in a study-team-promoted area
- Makes the promoted study prominent when the participant logs in

## Relationship to interest

```text
Ask if interested != Participant expressed interest
```

The participant must still take an explicit interest action.
